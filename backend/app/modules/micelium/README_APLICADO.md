# Micelium aplicado

Este módulo aplica a regra discutida:

- geodésica/Fibonacci/camadas: somente posicionamento inicial;
- ligações químicas/topológicas: fixas, vindas do template molecular/coarse-grained;
- interações físicas: recalculadas por Spatial Hash Grid + cutoff;
- visual speed: não altera química real;
- ambiente aplicado: recalcula o estado micelar, mas não redescobre ligações.
